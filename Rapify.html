Rapify has a similar origin to Wrapify with a slightly different goal. The intention with Rapify was to work on my data quality and cleaning skills since R is built for just that. I started this project prior to Wrapify in November of 2025. I decided to use this as an opportunity to work out how I would break down the data into something usable for my future project.

Built with R in VS Code with the Jupyter Notebook extension, Rapify focuses on data cleaning, organization, and visualization.

Using the dplyr package, I broke down the data set into "listening years" in which I could query these individual datasets to find yearly statistics like "most listened to song of 2018." Then I could make this data legible with the kable package, turning these results into user-friendly tables.

Once this was done, I wanted to take it a step further and build a machine learning model that could predict whether or not a user would skip a song based on preivous listening trends.

Finally, as an additional challenge, I used machine learning to predict a users skipping habits. Using existing data in which songs were labelled "skipped: True" or "Skipped: False" I was able to build an algorithm that predicts what songs a user is most likely to let play out, with ~77% accuracy.

The inaccuracies of this algorithm can likely be attributed to the size of the dataset. Most ML algorithms and libraries don't function nearly as well on larger datasets.

I Initially planned to use another more robust algorithm such as Random Forest. Random Forest handles large skewed datasets far better than most algorithms. However, upon training the model, it ran for 30 minutes and still had not finished, so, I ultimately decided to go with something a little less intense, OneR.

Perhaps in the future I will run Random Forest on this data to compare the results.

# mild cleaning, I dont want songs to be included that I haven't listened to at LEAST 10 times
skipped_songs <- streaming_history[streaming_history$song_title %in% names(which(table(streaming_history$song_title) >= 10)), ]

# ensure all variables are factors
skipped_songs[] <- lapply(skipped_songs, function(x) {
  if (is.character(x) | is.logical(x)) factor(x) else x
})

# removing columns that aren't neccesary
skipped_songs$ts = NULL
skipped_songs$ms_played = NULL
skipped_songs$track_url = NULL
skipped_songs$reason_start = NULL
skipped_songs$reason_end = NULL
skipped_songs$offline = NULL
skipped_songs$shuffle = NULL
skipped_songs$album_name = NULL

head(skipped_songs)

# install.packages("OneR")
library(OneR)

# using the OneR model to get my listening rules
skipped_songs_1R <- OneR(skipped ~ song_title, data = skipped_songs)

skipped_songs_pred <- predict(skipped_songs_1R, skipped_songs)
table(actual = skipped_songs$skipped, predicted = skipped_songs_pred)
