Rapify

Rapify is a simpler version of my project, Wrapify, written with R instead of python. This artifact is designed to display the listening history of a Spotify user. It was conceptualized a couple weeks back but work on it only began on Monday, November 17th, 2025.

R has great community support, and I was able to find resources very quickly that helped me achieve my desired goals. For example, when I got stuck on how to go about getting the totals for each listening year, I found this resource on counting using the dplyr package which made the process incredibly simple. I then found an example of the kable package that explained how to improve the look of my output, making it legible to end users.


                    # the total song counts for all time listening

I wanted to achieve these results through machine learning, but that proved incredibly difficult since I am not using numerical data. I was, however, able to use machine learning to predict skipping patterns. Using the OneR package, I was able to determine the likelihood of a song or artist being skipped with over 75% accuracy for both parameters. While it would have been nice to get around 90% accuracy, that I know can be achieved by using a smaller dataset or a stronger algorithm like Random Forest. 


                    # mild cleaning, I dont want songs to be included that I haven't listened to at LEAST 10 times
                    skipped_songs <- streaming_history[streaming_history$song_title %in% names(which(table(streaming_history$song_title) >= 10)), ]

                    # ensure all variables are factors
                    skipped_songs[] <- lapply(skipped_songs, function(x) {
                    if (is.character(x) | is.logical(x)) factor(x) else x
                    })

                    # removing columns that aren't neccesary
                    skipped_songs$ts = NULL
                    skipped_songs$ms_played = NULL
                    skipped_songs$track_url = NULL
                    skipped_songs$reason_start = NULL
                    skipped_songs$reason_end = NULL
                    skipped_songs$offline = NULL
                    skipped_songs$shuffle = NULL
                    skipped_songs$album_name = NULL

                    head(skipped_songs)

                    # install.packages("OneR")
                    library(OneR)

                    # using the OneR model to get my listening rules
                    skipped_songs_1R <- OneR(skipped ~ song_title, data = skipped_songs)

                    skipped_songs_pred <- predict(skipped_songs_1R, skipped_songs)
                    table(actual = skipped_songs$skipped, predicted = skipped_songs_pred)
