Wrapify is live! Check out my user-friendly webpage where you can upload your own data and get your personal metrics!

Wrapify was a personal project inspired by Spotify's Wrapped series. Created in 2025 as both programming and data analysis practice, this turned into a passion project that I hope to make publicly available for technical and non-technical users alike.

Built with Python and Jupyter Notebook, users who request their extended listening data from Spotify can insert that file into the program to receive personal metrics including how much time was spent listening to music, what their favorite songs, artists, and albums were, and how many times they revisited those songs and artists.

#---------------------------------------------------------------------------------
# Load multiple JSON files, merge them, clean the data, and export to CSV
#---------------------------------------------------------------------------------
def merge_json_files(folder):
    merged_data = pd.DataFrame()

    if not os.path.isdir(folder):
        print(f"Error: Folder '{folder}' not found.")
        return

    for filename in os.listdir(folder):
        if filename.endswith('.json'):
            filepath = os.path.join(folder, filename)
            try:
                with open(filepath, encoding='utf-8') as f:
                    data = pd.read_json(f)
                    merged_data = pd.concat([merged_data, data], ignore_index=True)
            except ValueError as e:
                print(f"Warning: failed to read {filename}: {e}")

    if merged_data.empty:
        print(f"No JSON rows found in '{folder}'.")
        return

    cleaned_data = merged_data.dropna(subset=['master_metadata_track_name'])

    keys_to_remove = [
        "platform", "conn_country", "ip_addr", "episode_name", "episode_show_name",
        "spotify_episode_uri", "audiobook_title", "audiobook_uri",
        "audiobook_chapter_uri", "audiobook_chapter_title",
        "incognito_mode", "offline_timestamp"
    ]

    for key in keys_to_remove:
        cleaned_data.pop(key)

    cleaned_data = cleaned_data.rename(columns={
        'master_metadata_track_name': 'song_title',
        'master_metadata_album_artist_name': 'artist_name',
        'master_metadata_album_album_name': 'album_name',
        'spotify_track_uri': 'track_url'
    })

    cleaned_data = cleaned_data[cleaned_data['ms_played'].between(20000, 900000)]

    cleaned_data['song_title'] = cleaned_data['song_title'].str.replace('$', 'S', regex=False)
    cleaned_data['album_name'] = cleaned_data['album_name'].str.replace('$', 'S', regex=False)
    cleaned_data['artist_name'] = cleaned_data['artist_name'].str.replace('$', 'S', regex=False)

    cleaned_data.to_csv('streaming_history.csv', index=False)
    print(f"Merged {len(cleaned_data)} total rows from {folder}/")

There were a few hurdles in the making of this project, but by far the biggest one I faced was visualization. In its original format, the results produced from my script were poorly formatted and difficult to read.

With the help of Seaborn, a statistical visualization library, I was able to construct clear tables and diagrams suitable for both visual and textual learners.

# The following code will produce the most listened to songs, artists, and albums of all time
#---------------------------------------------------------------------------------
with open('streaming_history.csv', encoding='utf-8') as f:
    data = pd.read_csv(f)

    top_tracks_summary = ( # ensure a song has the same artist and album name before adding it to the count
        data.groupby(['song_title', 'artist_name', 'album_name'])
            .size()
            .reset_index(name='play_count')
            .sort_values(by='play_count', ascending=False)
            .head(20)
    )
            
    top_artists_summary = (
        data.groupby(['artist_name'])
            .size()
            .reset_index(name='play_count')
            .sort_values(by='play_count', ascending=False)
            .head(20)
    )

    top_albums_summary = ( # ensure an album has the same artist before adding it to the count
        data.groupby(['album_name', 'artist_name'])
            .size()
            .reset_index(name='play_count')
            .sort_values(by='play_count', ascending=False)
            .head(10)
    )
    
    # calculate the total minutes, hours, and days played
    total_ms_played = data['ms_played'].sum()
    total_minutes = (total_ms_played / 1000) / 60
    total_minutes = total_minutes.astype(int)
    total_hours = int(total_minutes / 60)
    total_days = int(total_hours / 24)
)

For users particularly fond of music, Wrapify also calculates total listening time. This is displayed as a yearly comparison bar chart and broken down into minutes, hours, and days for precise insight.

This information is displayed as an overall bar plot, allowing users to compare their yearly listening times. However, I also broke this information down into minutes, hours, and days for each individual year for users who appreciate an exact number.
